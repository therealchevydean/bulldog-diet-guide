# French Bulldog Diet Guide 🐶

> **Production SEO & Affiliate Engine for French Bulldog Nutrition.**

A high-performance Next.js 15 programmatic SEO guide addressing what human foods are safe, healthy, and toxic for French Bulldogs. Specifically tailored to manage sensitive stomachs, food allergies, and brachycephalic airway restrictions (BOAS).

---

## 🌟 Features
- **Curated Database:** 20 veterinary-informed human food evaluations specific to Frenchie physiology.
- **Search & Instant Filters:** Client-side instant keyword filtering for Safe vs Toxic foods.
- **Programmatic SEO:** Dynamic `[slug]` pages with auto-generated **JSON-LD Schema (`FAQPage`)** for Google Rich Snippets.
- **Monetization Wired:** Amazon Associates tracking tag (`pugdietguide-20`) embedded with proper `rel="noopener sponsored"` attributes across:
  - Ergonomic tilted slow-feeder bowls (anti-gas & anti-air gulping).
  - Canine digestive enzymes & probiotics.
  - Hypoallergenic limited-ingredient treats.
- **Automated Sitemap & Robots:** Built-in `sitemap.xml` and `robots.txt` dynamic generation for instant Google Search Console indexing.

---

## 🛠 Tech Stack
- **Framework:** Next.js 15 (App Router, React 19)
- **Styling:** Tailwind CSS
- **Data Engine:** Static JSON dataset with pre-rendered static paths (`generateStaticParams`)
- **Hosting:** Vercel
